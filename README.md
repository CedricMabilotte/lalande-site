# Ferme de La Lande — annonce de transmission

Site statique (GitHub Pages) de l'annonce de transmission de la ferme de La Lande, Haute-Vienne.

Régénérer après modification du texte ou de l'adresse du site :

```
python3 outils/visuels.py . https://ADRESSE/
python3 outils/build.py . https://ADRESSE/
```

La version française de l'annonce fait référence.
